Pelican-Bike-Racing-Mini-Game 项目介绍

这是一个基于网页的迷你自行车竞速游戏，适合在电脑或手机浏览器中直接游玩。玩家可以控制自行车在赛道上竞速，体验简单快速的骑行乐趣。

主要功能：
1. 轻量级设计，加载速度快，无需安装额外软件。
2. 支持键盘操作或手机触屏控制。
3. 包含计分系统和竞速计时功能。

如何运行游戏：
目前仓库中提供的是完整的项目压缩包 game.zip。
第一步，下载 game.zip 并解压到你的设备上。
第二步，进入解压后的文件夹，找到 index.html 文件。
第三步，双击或使用浏览器打开 index.html，即可开始游戏。

项目目录结构说明：
src 目录：存放游戏核心源代码，包括 HTML、CSS 和 JavaScript 文件。
public 目录：存放静态资源文件，例如游戏图片和音效。
server 目录：存放本地服务器相关代码，用于测试或部署。
scripts 目录：存放项目构建或运行所需的脚本。
screenshots 目录：存放游戏运行的截图预览。
